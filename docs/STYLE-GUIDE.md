# دليل الهوية — موقع عمر العُمر

## الهوية
- التوجه: Luxury Minimal — هادئ، فاخر، بسيط، سريع.
- ثيم داكن فقط (لا يوجد Light Mode).
- الهدف: انطباع قوي خلال أول 5 ثوانٍ.

## الألوان (Tokens)
| Token | القيمة | الاستخدام |
|---|---|---|
| bg | #0D0D0D | خلفية الصفحة |
| card | #141414 | البطاقات |
| text | #E8E4DE | عناوين ونصوص |
| muted | #9B978F | نصوص ثانوية |
| gold | #C9A96E | CTA، خطوط، نقاط |
| gold-hover | #D8BE8C | Hover |
| glow | rgba(201,169,110,.25) | توهج البطاقات |
| divider | rgba(232,228,222,.12) | حدود وفواصل |

- نسبة الذهبي ≤ 10% في أي شاشة.

## الخطوط
| الدور | الخط |
|---|---|
| عناوين عربي | Amiri (Serif فاخر) |
| نصوص عربي | IBM Plex Sans Arabic |
| لاتيني | Inter / Cormorant Garamond |

| العنصر | ديسكتوب | جوال |
|---|---|---|
| H1 | 64 | 36 |
| H2 | 40 | 28 |
| H3 | 24 | 20 |
| Body | 18 | 16 |
| Caption | 13 | 13 |

- ارتفاع السطر للنصوص: 1.9.

## التخطيط
- Container ‏1200px | Grid ‏12 عمود | Gutter ‏32.
- Padding الأقسام: 120 ديسكتوب / 72 جوال.
- Radius: أزرار 999 (Pill) / بطاقات 14.

## الحركة
- Fade / Slide ‏16px فقط، ‏240ms ease-out.
- احترام prefers-reduced-motion.

## المكوّنات
- أزرار: Gold أساسي / Outline ذهبي / Ghost — ارتفاع 52 (جوال 48).
- بطاقات: bg card + border divider، وعند Hover حد ذهبي + Glow.
- Timeline: خط ذهبي 2px + نقاط 10px.

## الممنوع
- قوالب جاهزة.
- ازدحام عناصر.
- مؤثرات مبالغ فيها.
- صور لا تخدم الهوية.
- إضافة أقسام دون اعتماد.
